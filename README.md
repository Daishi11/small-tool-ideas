# Small Tool Ideas

A place for suggesting small, focused software tools that could make something easier, less annoying, or simply more convenient.

I enjoy building small utilities that solve a specific problem without turning into huge software projects.

That can include browser extensions, Python utilities, automation scripts, game helpers, small desktop tools, converters, calculators, puzzle helpers, modding utilities, and other oddly specific pieces of software.

This repository is primarily an idea board. The actual discussions and suggestions live in GitHub Discussions.


## What kind of ideas am I looking for?

The best suggestions are usually things that make you think:

> "Why do I have to do this manually every time?"

or:

> "This would probably be really easy if a tiny program did it for me."

Examples include:

- browser extensions
- small Python or desktop utilities
- game helpers and modding tools
- automation scripts
- converters and batch-processing tools
- calculators and planners
- puzzle or word-game helpers
- configuration helpers
- small quality-of-life tools
- weirdly specific utilities that solve one annoying problem well

The tool does not need to appeal to thousands of people.

If it solves a real problem for a handful of people, that can already make it interesting.


## Suggest an idea

Have something in mind?

Open a discussion here:

https://github.com/Daishi11/small-tool-ideas/discussions/categories/ideas

Please describe:

- what problem you are trying to solve
- what you currently have to do manually
- what you would like the tool to do
- where you would use it
- whether you know of existing tools that almost solve the problem

You do not need to write a technical specification.

Describing the annoying part clearly is usually more useful.


## Scope

I am mainly interested in small and reasonably self-contained projects.

I am not currently looking for ideas for full games, large applications, SaaS platforms, social networks, or projects that would require months of continuous development.

I already have a large long-term project:

[Cyan Moon – The Simulation Program](https://store.steampowered.com/app/5176400/Cyan_Moon__The_Simulation_Program/)

For side projects, I deliberately prefer tools that can remain focused.


## Commissions

I am also open to paid commissions for small custom tools.

That can include things such as browser extensions, Python utilities, automation scripts, game helpers, small desktop programs, or similarly focused software.

A suggestion posted here is not automatically a commission.

If you specifically want a tool made for you and are interested in paying for the development, mention that in your suggestion or contact me separately.

Large applications and full games are generally outside the scope of commissions I am interested in.


## No promises

Submitting an idea does not mean that I will implement it.

I may:

- build it as suggested
- change or simplify the idea
- combine it with another suggestion
- decide that an existing tool already solves the problem
- leave it for later
- or decide not to build it

I read the suggestions because I genuinely enjoy finding small problems that are interesting to solve.


## Ideas and ownership

Ideas submitted here are suggestions, not exclusive development requests.

By posting a suggestion, you acknowledge that I or other people may independently use, adapt, discuss, or implement the general idea without creating an obligation to provide payment, royalties, ownership, exclusivity, or attribution.

If a project is being developed as a paid commission, its terms should be agreed separately before development begins.

Please do not submit confidential information, private credentials, proprietary source code, or material that you do not have permission to share.
